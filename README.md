# Консольная игра «Морской Бой» на Python

Минималистичная реализация классической игры «Морской бой» для двух игроков в одном терминале. Главные особенности: полная секретность (корабли скрыты у обоих игроков во время ходов) и автоматическое обведение точками потопленных кораблей.

---

## 🚀 Быстрый запуск

1. Убедитесь, что установлен Python 3.x.
2. Запустите игру из терминала:
   ```bash
   python battleship.py
   ```

---

## 🛠️ Архитектура и структура кода

Код построен на ООП-архитектуре и делится на два основных класса и управляющие функции.

### 1. Основные классы
* **`Ship` (Корабль):** 
  * Хранит свой размер, координаты на поле и множество (`set`) полученных попаданий.
  * Метод `is_sunk()` возвращает `True`, если количество попаданий сравнялось с размером корабля.
* **`Board` (Игровое поле):**
  * Хранит матрицу 10х10 и список объектов кораблей.
  * `display(hide_ships)` — визуализирует сетку. Если `hide_ships=True`, заменяет символы живых кораблей (`■`) на туман войны (`~`).
  * `can_place_ship()` / `place_ship()` — проверяют границы поля и правило соседства (зазор в 1 клетку вокруг кораблей) перед размещением.
  * `auto_place_ships()` — реализует случайную расстановку флота по алгоритму Bruteforce.
  * `receive_shot()` — обрабатывает выстрел, меняет состояние ячейки (`X` — попал, `•` — промах) и возвращает статус: `repeat` (повтор), `miss` (мимо), `injured` (ранен) или `killed` (убит).
  * `mark_surrounding()` — автоматически заполняет промахами (`•`) клетки вокруг полностью уничтоженного корабля.

### 2. Функции управления игрой
* **`clear_screen()`** — очищает консоль через системные команды (`cls`/`clear`) и делает отступ в 30 строк, предотвращая подглядывание.
* **`setup_player_board()`** — инициализирует поле для конкретного игрока. Предлагает выбор между ручным вводом координат и автоматической генерацией.
* **`play_game()`** — главный игровой цикл. Управляет очередностью ходов, проверяет координаты выстрелов и фиксирует победу, когда `board.all_ships_sunk()` возвращает `True`.

## 🎮 Игровой процесс
1. **Расстановка:** Игроки по очереди выбирают ручной или автоматический режим размещения флота (от 1 до 4 палуб).
2. **Экран ширмы:** Перед каждым ходом игра замирает и требует подтверждения, что соперник не смотрит на экран.
3. **Битва:** Игрок видит свои попадания/промахи и стреляет по скрытому полю врага. При попадании ход сохраняется. Игра заканчивается полным уничтожением флота одного из участников.

bash```
# Ввод количества элементов и заполнение кортежа
n = int(input("Введите количество чисел в кортеже: "))
numbers = tuple(int(input(f"Введите число {i + 1}: ")) for i in range(n))

print("\nВаш кортеж:", numbers)

if len(numbers) > 0:
    # 1) Вывод элементов и среза
    print("Первый элемент:", numbers[0])
    print("Последний элемент:", numbers[-1])
    # Индексы в Python начинаются с 0: 2-й элемент имеет индекс 1, 3-й — индекс 2.
    # Верхняя граница среза не включается, поэтому указываем [1:3].
    print("Срез со второго по третий элемент:", numbers[1:3])

    # 2) Подсчет вхождений и поиск первого индекса
    target = int(input("\nВведите число для поиска: "))
    count = numbers.count(target)
    print(f"Количество вхождений числа {target}: {count}")

    if count > 0:
        print(f"Индекс первого вхождения: {numbers.index(target)}")
    else:
        print("Такого числа нет в кортеже.")
else:
    print("Кортеж пуст.")

```
